# 決算書は嘘をつく

決算書を読み解いて粉飾を暴く、スマートフォン向けのミステリーノベルゲームです。

物語を読み、分岐では「資料」（決算の推移・注記・登記情報・アプリのレビュー）を開いて、いちばん怪しい点を選びます。正解すると「推論」が推理ノートに記録され、物語が先へ進みます。外れた選択肢は理由が示され、選択肢に戻ります。

## 遊び方

```sh
npm start          # http://localhost:8080 を開く（python3 の簡易サーバー）
```

ビルドは不要です。静的ファイルなので GitHub Pages などにそのまま置けます。ホーム画面に追加すればオフラインでも遊べます（PWA）。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面とデザイン（ワイヤーフレームの配色・書体に準拠） |
| `js/story.js` | 物語データ（シーン・選択肢・資料・推論） |
| `js/engine.js` | 進行エンジン（描画、資料シート、推理ノート、セーブ） |
| `sw.js` / `manifest.webmanifest` | オフライン対応とホーム画面アイコン |
| `scripts/validate-story.js` | 物語データの整合性チェック |

## 物語を書き足す

`js/story.js` の `scenes` にシーンを足します。

- `text` … `paragraphs` を表示してタップで `next` へ。`showChoice: true` で直前の選択を吹き出し表示、`gain` で推論を獲得。
- `choice` … `recap`・`prompt`・`docs`（資料 id）・`options`。選んだ先のシーンの `next` がこの分岐自身なら「外れ」として扱われ、その選択肢は消し線になります。
- `end` … 章の終わり。

書き足したら `npm test` で参照切れや行き止まりがないか確認してください。
