# 決算書は嘘をつく

決算書を読み解いて粉飾を暴く、スマートフォン向けのミステリーノベルゲームです。

ケース1「Nulo」（プロローグ＋全5章＋幕間3つ＋終章＋エピローグ）を収録。物語を読み、分岐では「資料」（決算表・登記・適時開示・業界ニュースなど）を開いて選択肢を選びます。正解すると「推論」を得て、後の分岐で武器になります。選択によって「確度」とフラグが変わり、終章で4つの結末（完全な論証／遅すぎた正解／逃げ切り／罠にかかる）に分かれます。

デザインはワイヤーフレームの「曲線タイポ・アナログ版」に準拠しています。

## 遊び方

```sh
npm start          # http://localhost:8080 を開く（python3 の簡易サーバー）
```

ビルドは不要です。静的ファイルなので GitHub Pages などにそのまま置けます。ホーム画面に追加すればオフラインでも遊べます（PWA）。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面とデザイン（ワイヤーフレームの配色・書体に準拠） |
| `js/story.js` | 物語データ（シーン・選択肢・資料・推論） |
| `js/engine.js` | 進行エンジン（描画、資料シート、推理ノート、セーブ） |
| `sw.js` / `manifest.webmanifest` | オフライン対応とホーム画面アイコン |
| `scripts/validate-story.js` | 物語データの整合性チェック |

## 物語を書き足す

`js/story.js` の `scenes` にシーンを足します。

- `pages(id, chapter, [[段落…], [段落…]], next)` … 本文。1つの配列が1画面。
- `choice(id, chapter, { recap, prompt, docs, retry, next, options })` … 分岐。各選択肢は `judge`（`o`/`tri`/`x`）、`text`（選んだ後の本文）、`gain`（推論）、`delta`（確度）、`flags`、`requires`（必要な推論）を持てます。`retry` の分岐で外すと理由を読んで分岐に戻り、その選択肢は消し線になります。
- `route` … 結末の判定。`rules` を上から評価します。
- 資料は `docs` に `table` / `article` / `inferences` の形で書きます。

書き足したら `npm test` で参照切れや行き止まりがないか確認してください。
